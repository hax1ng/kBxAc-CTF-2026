## TL;DR

A much bigger sibling of [Crossword 1](../crossword-1/): a `104 × 101` codeword crossword rendered as a PNG, numbers instead of letters, same "serialise the solved grid row by row" flag rule. The intimidating part is the size, not the cryptography. Once you notice the regular `40 × 40` cells you can reduce ~10,500 cells to only **27 unique tiles**, hand-label them, crack the substitution from a handful of long rare words, and let a script do the tedious row-by-row flag assembly.

## What We're Given

A single large crossword image (`crossword.png`, 4160 × 4040). Every letter is replaced by a number 1–26, but **not** in `1=A` order — each number consistently maps to one letter, i.e. a simple substitution drawn as a crossword. The accompanying `instructions.txt` gives the flag rule: read each row left to right, ignore black/empty cells, join rows with `_`, wrap in `kBxAc{...}`.

## Initial Recon

Every cell is exactly `40 × 40` px:

```
4160 / 40 = 104 columns
4040 / 40 = 101 rows
```

Crucially, cells holding the same number are **pixel-for-pixel identical**, so there's no need to OCR ~5,000 cells. Split the image into tiles and group identical tiles by their raw bytes — there are exactly **27 unique tiles**: one all-black "empty" tile plus the 26 numbered tiles.

Labelling one copy of each unique tile (in order of first appearance) by eye gives:

```python
tile_values = [None, 13, 24, 2, 25, 16, 21, 11, 3, 15, 19, 6, 5, 26,
               10, 18, 8, 9, 4, 23, 20, 17, 12, 22, 7, 14, 1]
```

At this point the picture is just an ordinary grid of numbers.

## The Vulnerability / Core Concept

Recovering the substitution is a cryptogram solve: repeated numbers are repeated letters, and crossing words must agree at intersections. A few long, unusual answers crack it open fast.

The biggest lever was a 19-character entry whose repeat pattern matches **XENOTRANSPLANTATION**, pinning 11 letters at once:

```
11=X 6=E 24=N 2=O 25=T 16=R 12=A 19=S 14=P 20=L 9=I
```

With those filled in, more rare words fall out: `XERORADIOGRAPHIC` (→ `1=D 22=G 3=H 4=C`), then `QUINQUAGENARIAN` (`10=Q 15=U`), `ZYGODACTYLOUS` (`21=Z 7=Y`), `KALEIDOSCOPIC` (`13=K`), `JUVENESCENCE` (`26=J 23=V`), `KEYBOARDIST` (`8=B`), `ZWITTERIONIC` (`17=W`), `JUSTIFIABLE` (`18=F`). Only `M` is left, so `5=M`. The complete map:

```
 1=D  2=O  3=H  4=C  5=M  6=E  7=Y  8=B  9=I 10=Q 11=X 12=A 13=K
14=P 15=U 16=R 17=W 18=F 19=S 20=L 21=Z 22=G 23=V 24=N 25=T 26=J
```

`QUINTESSENTIAL`, `XYLOGRAPHIC`, `ZOOPLANKTON`, `XERORADIOGRAPHY` appearing correctly elsewhere are a nice sanity check.

## Building the Exploit

[`solve.py`](solve.py) does the mechanical part: tile each 40×40 cell, map identical bitmaps to the hand-labelled values, then build the flag exactly as `instructions.txt` says.

```python
seen_tiles = {}
grid = []
for row in range(rows):
    decoded_row = []
    for column in range(columns):
        tile = image.crop((column*CELL, row*CELL, (column+1)*CELL, (row+1)*CELL)).tobytes()
        seen_tiles.setdefault(tile, len(seen_tiles))
        decoded_row.append(tile_values[seen_tiles[tile]])
    grid.append(decoded_row)
assert len(seen_tiles) == 27

flag_rows = ["".join(number_to_letter[v] for v in row if v is not None) for row in grid]
flag = "kBxAc{" + "_".join(flag_rows) + "}"
```

One gotcha: the row strings contain lots of apparently random letters around the recognisable words. Those aren't decoding errors — they're letters belonging to **vertical** answers. The rule says keep **every** filled cell in each row, so they all stay.

## Running It

```
$ python3 solve.py

```

## Key Takeaways

- The scary part of a giant codeword is **size, not cryptography**. Reducing a 10,000+ cell image to 27 distinct tile types makes the whole thing tractable.
- A handful of long, uncommon words (`XENOTRANSPLANTATION`, `QUINQUAGENARIAN`, …) can reveal almost the entire substitution alphabet before you touch the short words.
- Let a script handle the row-by-row serialisation — manual transcription of a 4,960-char flag is a guaranteed typo.
